# Cross-Asset Electricity Preanalysis

Preanalysis component of my bachelor thesis at TUM, investigating whether cross-asset
variables (fuel commodities, financial/market indicators, and cross-border prices) carry
predictive information about German (and French) day-ahead electricity prices. This
repository covers data preparation, descriptive analysis, and statistical testing that
inform the feature sets exported for the subsequent forecasting stage.

## Contents

- `data/` — raw input series (electricity, gas, coal, carbon, EUR/USD, VSTOXX, STOXX
  Utilities, gas storage, Norway hydro reservoirs, French load/generation forecasts).
- `analysis.ipynb` — the main preanalysis notebook.
- `output/` — CSV exports generated by the notebook.
- `requirements.txt` — pinned Python dependencies.

## Notebook structure (`analysis.ipynb`)

1. **Data Importing** — loads the raw CSV files, standardizes columns, and aligns all
   series to a common daily calendar.
2. **Overview** — descriptive plots of electricity prices alongside the fuel, financial,
   and supply indicators.
3. **Metrics** — stationarity checks (ADF) and Granger causality tests, including
   regime-specific variants.
4. **CSV Export** — exports the assembled feature sets for Models 1–5 to CSV files for
   downstream use.

## Setup

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/jupyter notebook analysis.ipynb
```
